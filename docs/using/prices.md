# Prices and Counters

Prices live on the print page, not in the editor. Open a ticket with **Print**,
then press **Edit prices**.

## Prices

A ticket has one or more prices. Each is an amount in the main currency, and
the dialog states which currency that is.

Prices are ordered, and the order is the order they appear on the print page.
Drag a price by its handle to reorder. Press **Add price** for another, or the
delete button on a row to remove one.

Removing a price does not remove sales already recorded against it.

## Counters

Each price keeps its own counter. The counter advances by one for every item
sold at that price, whether it was printed or only recorded.

Counters are per day. On a new day every counter starts again from its
configured starting number, so the first ticket of the day is number one unless
you set otherwise.

The print page shows **Next #N** under each price: the number the next ticket at
that price will carry.

## Correcting a counter

If paper jams, or a ticket is spoiled, the counter and the paper disagree.

Open the overflow menu next to **Counters** and choose the counter action. Set
the number the next ticket should carry and confirm.

A correction is never silent. It is written as a counter adjustment showing the
old number, the new number and a reason, and it appears in **Today's activity**
alongside sales. The sales record therefore explains every gap in the
numbering.

## Numbering format

Number padding is set per ticket in the editor, under the numbering section of
a selected number field. Padding of four prints ticket 7 as `0007`.
